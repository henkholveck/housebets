# Housebets Sportsbook · clickable prototype

Contest entry for Housebets Contest Labs: five linked pages (Sports home, Live, Football, Match page, Bet slip + My bets), desktop 1440px and phone 390px.

- Front end only, single `index.html`, no build step.
- Sample data only. No real players, no real money.
- Singles only, decimal odds, stakes in USDT.
- Use the **Prototype** button in the corner to jump to any state: odds changed, suspended, bet failed then retry, bet placed, cash out, nothing live.
